# Driver version history 

---------------------------------------------------------------------------------------------------------------
Version : 2.0.16
Date: 24/06/2025
Comments :
- Add missing declarations for vl53lmz_get_ranging_frequency_x256() / vl53lmz_set_ranging_frequency_x256()
- Modified glare_filter get/set functions to not generate compiler warnings.
- Skipped version 2.0.15 due to confusion about update history.
---------------------------------------------------------------------------------------------------------------

---------------------------------------------------------------------------------------------------------------
Version : 2.0.14
Date: 14/11/2024
Comments :
- Fix compatibility with VL53L7.
- New API functions to allow more precise setting of ranging frequency:
  -- vl53lmz_get_ranging_frequency_x256() / vl53lmz_set_ranging_frequency_x256()
---------------------------------------------------------------------------------------------------------------

---------------------------------------------------------------------------------------------------------------
Version : 2.0.13
Date: 12/11/2024
Comments :
- Updates in vl53lmz_buffers.h file to align it with L8CX ULD v2.0.0 (updated spread spectrum settings)
- Enable download FW checksum feature.
- Added SPI example project. Aligned I2C and SPI projects.
- Added GPIO pin allocation PDF files in example projects.
---------------------------------------------------------------------------------------------------------------

---------------------------------------------------------------------------------------------------------------
Version : 2.0.11
Date: 12/03/2024
Comments :
- Changed method used to set module_type so that it correctly distinguishes between L5 and L7 parts.
- Modified vl53lmz_is_alive() to only store device_id and revision_id.
- Moved to MM FW v1.8 (modified field order in low_reflectance_filter_t)
---------------------------------------------------------------------------------------------------------------

---------------------------------------------------------------------------------------------------------------
Version : 2.0.10
Date: 07/12/2023
Comments :
- Fixed wrong conversion of Ambient and Histogram values in Example_12. Values were a factor of 2x too low.
- Fixed incorrect sizing of cnh_data_buffer_t.
- Fixed incorrect comparison for is_auto_stop_enabled.
- Added VL53LMZ_POWER_MODE_DEEP_SLEEP mode.
- Include MM FW v1.7 which contains:
.... Improved rad2perp for L8
.... Improved wrap-around check algo
.... Option to skip intr on first two frames of detection thresholds
.... Calculation of a FW checksum
.... Fix for incorrect operation with very negative values of CNH start_bin
.... Added first_bin to sci_persistent_data[2][31:16]
---------------------------------------------------------------------------------------------------------------

---------------------------------------------------------------------------------------------------------------
Version : 2.0.9
Date : 25/07/2023
Comments :
- Fixed issue in  vl53lmz_enable/disable_internal_cp functions which prevented use with VL53L7CH.
- Added module_type to VL53LMZ_Configuration to provide a public location to read the module type. This
field is set during calls to vl53lmz_is_alive() and vl53lmz_init().
